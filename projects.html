What We're Working On

The best way to learn technology is to put it into practice. MCC ICT Club members explore computing through hands-on projects, collaborative activities, and technical workshops. From building computers and developing custom hardware to troubleshooting and repairing electronics, this is where we showcase what our members are building, learning, and accomplishing.

Student Projects

Explore projects designed and developed by ICT Club members. Some are works in progress, while others demonstrate completed projects and skills developed through hands-on learning.

PC Building

Artemis is building a personal computer! Our PC building workshop helped clarify the design choices, and an upcoming workshop will help put it all together. Pictures of the completed build are coming soon!

Cyberdeck Laptop

Collin is building a cyberdeck, a custom portable computer built from scratch. The build pairs a Raspberry Pi 3 Model B+ with a 7-inch touchscreen and a mini keyboard with a built-in touchpad. Powered by battery banks, the project also includes plans for a 3D-printed chassis.

Pictures of the build are coming soon, so check back as it comes together!

Club Website

The website you're reading right now is a club project! Since September, club leadership has built and maintained it by hand using HTML and CSS, adding the events calendar, office hours, workshop guides, and this project showcase.

The site's code lives on GitHub, so it's a great way to put what you learned in Git & GitHub 101 into practice. Members can contribute anything from fixing a typo to designing a new page. Talk to an officer if you'd like to help!
